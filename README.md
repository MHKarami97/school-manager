# مدیریار (School Manager)

سامانه‌ای مدرن و آفلاین برای برنامه‌ریزی خودکار برنامه هفتگی مدارس — دوره ابتدایی، متوسطه اول و متوسطه دوم —
ساخته‌شده با **Vue 3**، **TypeScript** و **Tailwind CSS v4**، و به‌صورت **PWA** نصب‌شدنی روی موبایل و دسکتاپ.

مخزن: <https://github.com/MHKarami97/school-manager>

## امکانات

- پوشش دوره‌های تحصیلی: ابتدایی (پایه اول تا ششم)، متوسطه اول (هفتم تا نهم)، متوسطه دوم (دهم تا دوازدهم).
- پایه‌ها، درس‌ها و ساعت هفتگی هر درس به‌صورت کانفیگ (`src/config`) و قابل ویرایش/افزودن هستند.
- شیفت صبح (۷:۴۵–۱۲:۳۰) و ظهر (۱۲:۴۵–۱۷:۳۰) با طول زنگ ۴۵ دقیقه و تفریح ۱۵ دقیقه به‌صورت پیش‌فرض، و کاملاً قابل ویرایش
  (شامل فعال/فعال کردن و تنظیم زنگ تفریح ناهار).
- ویزارد ۶ مرحله‌ای: مخاطب (خودم/مدرسه) ← دوره تحصیلی ← پایه‌ها ← شیفت و زمان‌بندی ← معلم‌ها ← بازبینی و ساخت.
- موتور چیدمان با رعایت قوانین آموزشی:
  - هیچ درسی در یک روز دوبار تکرار نمی‌شود (قانون عرضی).
  - هیچ درسی در یک شماره‌زنگ ثابت در روزهای متفاوت هفته دوبار تکرار نمی‌شود (قانون طولی).
  - قرآن/دینی همیشه در زنگ اول قرار می‌گیرد (استثنای اول).
  - ورزش با برنامه مشخص مدرسه می‌تواند پشت‌سرهم باشد (استثنای دوم) — از طریق ویرایشگر با درگودراپ قابل تنظیم است.
- در متوسطه اول/دوم، ساعت تدریس هر درس به‌صورت عادلانه (max-min fairness) بین معلم‌های همان درس توزیع می‌شود و اضافه‌کار هشدار داده می‌شود.
- ویرایشگر برنامه: جابجایی خانه‌ها با درگودراپ، تفییر درس/معلم هر خانه، ذخیره تفییرات.
- ذخیره، فهرست، ویرایش مجدد و حذف برنامه‌ها در IndexedDB مرورگر.
- خروجی PDF از طریق چاپ مرورگر (با چیدمان افقی A4 اختصاصی) و خروجی تصویر PNG.
- نصب به‌صورت PWA؛ در صورت انتشار نسخه جدید، نوار پایین صفحه با دکمه «به‌روزرسانی» نمایش داده می‌شود.
- طراحی کاملاً واکنش‌گرا (موبایل تا دسکتاپ) با فونت Vazirmatn و راست‌به‌چپ.

## ساخت پروژه

```
src/
  config/       # دوره‌ها، کاتالوگ درس‌ها، ساعت هفتگی هر پایه، پیش‌فرض شیفت/زنگ
  types/        # تایپ‌های مشترک TypeScript
  db/           # لایه IndexedDB (idb)
  stores/       # Pinia stores: teachers, schedules, wizard
  utils/        # scheduler.ts (موتور چیدمان)، teacher-assignment.ts (عدالت معلم‌ها)،
                # generate-schedule.ts (پل ویزارد ↔ موتور)، export.ts (PDF/تصویر)
  components/
    layout/     # AppHeader, AppFooter
    wizard/     # شش گام ویزارد
    schedule/   # ScheduleGrid, CellEditorModal, PrintableSchedule
    UpdateToast.vue   # نوار اطلاع‌رسانی نسخه جدید PWA
  views/        # HomeView, WizardView, SavedSchedulesView, ScheduleEditorView
  router/       # مسیرهای برنامه (hash history برای سازگاری با هاست استاتیک)
```

## محدودیت‌های شناخته‌شده و مسیر توسعه بعدی

- ساعت هفتگی درس‌های متوسطه اول/دوم در `curriculum.config.ts` برآوردی اولیه است و باید مطابق سرفصل رسمی وزارت
  آموزش‌وپرورش مدرسه شما در همان فایل نهایی/ویرایش شود.
- قفل‌کردن دستی ساعت‌های ورزش پیش از چیدمان خودکار (فیلد `lockedSportCells`) در تایپ‌ها و استور تعریف شده اما هنوز
  رابط کاربری اختصاصی در ویزارد ندارد؛ به‌جای آن، بعد از ساخت برنامه می‌توانید در ویرایشگر با درگودراپ همان نتیجه
  (زنگ‌های پشت‌سرهم ورزش) را دستی بچینید.
- آیکون‌های PWA به‌صورت SVG ساده هستند؛ برای برندینگ نهایی بهتر است با لوگوی واقعی مدرسه/برند جایگزین شوند.
