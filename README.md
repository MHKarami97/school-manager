# مدیریار (School Manager)

سامانه‌ای مدرن و وب‌محور برای برنامه‌ریزی خودکار برنامه هفتگی مدارس، ساخته‌شده با **Vue 3**، **TypeScript** و **Tailwind CSS v4**.

## امکانات

- پوشش دوره‌های تحصیلی: ابتدایی (اول تا ششم)، متوسطه اول (هفتم تا نهم)، متوسطه دوم (دهم تا دوازدهم)، همراه با دروس هر پایه، به‌صورت **کانفیگی و قابل ویرایش**.
- موتور ساخت برنامه بر اساس قوانین آموزشی (عدم تکرار طولی/عرضی درس، استثنای قرآن در زنگ اول، استثنای ورزش، رعایت عدالت در چندمعلمی).
- ویرایش دستی نتیجه تولیدشده (درگ و درپ).
- مدیریت معلم‌ها در مرورگر (IndexedDB) برای استفاده مجدد.
- ذخیره، بازیابی و مدیریت برنامه‌های ساخته‌شده.
- خروجی PDF (از طریق چاپ مرورگر) و خروجی تصویر (PNG).
- رابط و ریسپانسیو کامل برای دسکتاپ، تبلت و موبایل.

## پیش‌نیازها

- Node.js 20+
- npm 10+

## اجرای محلی

```bash
npm install
npm run dev
```

## بیلد

```bash
npm run build
npm run preview
```

## ساخت پروژه

```
src/
  config/     # تنظیمات دوره، پایه، درس و زمان‌بندی پیش‌فرض
  stores/     # Pinia stores (تعامل با IndexedDB)
  db/         # لایه دسترسی به IndexedDB
  utils/      # الگوریتم ساخت برنامه و خروجی PDF/تصویر
  views/      # صفحات اصلی
  components/ # کامپوننت‌های قابل استفاده مجدد
  router/     # مسیریابی
```
